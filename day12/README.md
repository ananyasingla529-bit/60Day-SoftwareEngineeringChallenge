# Day 12 - Reverse String

## Phase

String Processing

## Problem

The goal of Day 12 is to practice basic string manipulation by reversing a given string.

## What I Learned

* How to access characters of a string using indexes
* How to traverse a string from the end to the beginning
* How to build a reversed string
* How to analyze time and space complexity

## Approach

1. Take a string as input.
2. Start from the last character using its index.
3. Move backwards through the string.
4. Add each character to a new string.
5. Print the original and reversed strings.

## Example

**Input:**

```text
hello
```

**Output:**

```text
Original string: hello
Reversed string: olleh
```

## Complexity Analysis

* **Time Complexity:** `O(N)`
  The string is traversed once.

* **Space Complexity:** `O(N)`
  A new string is created to store the reversed string.

Where `N` is the length of the input string.
